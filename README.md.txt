Retail Store Sales Analysis

Project Overview

This project focuses on analyzing retail store sales data using SQL and Power BI. The main objective is to understand sales performance, customer activity, product performance, order status, and payment methods through data analysis and interactive dashboards.

Tools Used

- PostgreSQL – Database management and SQL analysis.
- DBeaver – SQL query execution.
- Power BI Desktop – Data visualization and dashboard creation.   

Dataset Details

The project uses generated sample retail data with the following tables:

Table       |  Records
Customers   |  100
Products    |  50
Orders      |  500
Order Items |  995
Payments    |  500

Note: This project uses synthetic sample data, not real customer or business records.

SQL Analysis Performed

- Customer-wise sales analysis
- Category-wise sales analysis
- Order status analysis
- Payment method analysis
- Top products by quantity and revenue
- Average Order Value calculation
- Customer purchase ranking
- Monthly sales analysis
- Data validation and duplicate checks

Power BI Dashboard

Created an interactive dashboard with two main report pages.

Page 1 – Sales Overview

- Total Revenue
- Total Orders
- Total Customers
- Order Status Analysis

Page 2 – Sales Analysis

- Category-wise Sales Analysis
- Payment Method Analysis
- Monthly Sales Analysis
- Top Products by Quantity

Interactive Features

- Category Slicer
- City Slicer
- Synced slicers across report pages

Key Insights

- Total Revenue: Approximately ₹45.11 Million
- Total Orders: 500
- Total Customers: 100
- Each of the four order statuses contains 125 orders.
- Card and UPI are the leading payment methods by transaction count, with 167 payments each.

Project Outcome

This project helped develop practical skills in SQL querying, relational database analysis, data validation, Power BI visualization, and interactive dashboard development.
